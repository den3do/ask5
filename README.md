# 易數神策 (ask5) ‧ 六爻梅花易數占卜與終身命理合盤系統

> 線上體驗網址：**[https://den3do.github.io/ask5/](https://den3do.github.io/ask5/)**

---

## 📖 專案簡介

本專案是一個現代化、架構嚴謹的線上易經命理與占卜 Web 應用程式。
融合傳統**「梅花易數」**與**「文王六爻納甲排盤及斷卦演算法」**，打造出三大核心模組：

1. **一事一占（短期吉凶預測與白話評語）**
2. **個人終身卦（一生大運與命理深度報告）**
3. **雙人命卦合盤（契合度評分與具體相處指引）**

全系統採用 **100% 純前端無伺服器（Client-Side SPA）** 設計，完全不需要後端伺服器或外部 API，運算速度極快，並透過 GitHub Actions 自動構建部署至 GitHub Pages。

---

## 🔮 三大核心功能說明

### 模組一：一事一占（吉凶判斷引擎）
- **起卦方式**：接收 3 個靈感數字（數字1除以8為上卦、數字2除以8為下卦、數字3除以6為動爻）。
- **完整排盤**：
  - 自動帶入當前「年月日時」四柱干支（立春換年、二十四節氣換月、五鼠遁時）。
  - 自動排出：**主卦、變卦、互卦**。
  - 自動標註：**世爻、應爻、六親**（父母/兄弟/子孫/妻財/官鬼）、**六神**（青龍/朱雀/勾陳/螣蛇/白虎/玄武）。
  - 自動計算：**當日旬空（空亡）、月破（與月建相沖）、日破（與日建相沖）**。
- **加減分權重演算法**：
  - **用神自動鎖定**：財運看妻財、事業工作看官鬼、感情看妻財/官鬼、學業健康看父母、平安解憂看子孫、合夥看兄弟。
  - **月建日辰旺衰**：得月令當旺/相生加分，休囚死扣分；得日辰暗生加分，受日辰暗剋扣分；逢月破/日破/旬空大幅扣分。
  - **世應與用神關係**：用神持世大吉、用神生世吉、用神剋世凶、世爻生用神耗洩。
  - **動變爻影響**：動爻生剋世爻與用神、動爻**化回頭生**（大加分）、**化回頭剋**（大扣分）、**化進神**、**化退神**、**化入空亡**。
- **輸出評定**：
  - 映射至 7 個等級徽章：**【大凶、凶、小凶、平、小吉、吉、大吉】**。
  - 生成條理分明的**白話文綜合斷語與具體行動錦囊**。
  - 提供**「一鍵複製 AI 提示詞」**，方便匯出給 ChatGPT、Claude 等大語言模型進一步追問。

### 模組二：個人終身卦（深度命理分析報告）
- **生辰輸入**：支援 **國曆（公曆）** 與 **農曆（陰曆）** 雙向換算，時辰提供十二地支下拉選單，並支援 **「不清楚 / 無時辰」** 起卦（依據邵康節天地人三才命卦法）。
- **生成長篇結構化報告**，章節包含：
  1. **【命卦天地格局】**：主卦、互卦、八宮歸屬、卦辭白話綜述。
  2. **【核心心性與性格特質】**：世爻五行（木仁/火禮/土信/金義/水智原型）＋ 六親深層驅動力 ＋ 六神處世氣場，深入剖析性格優勢與**性格盲點心靈修為**。
  3. **【天賦天職與事業發展】**：世爻角色定位（體制管理/專技文創/商務資本/企劃幕僚）＋ 世爻五行利基產業推薦清單 ＋ 職場發展策略。
  4. **【一生財帛與財庫格局】**：財爻旺衰、世財關係（財持世、子孫生財、兄弟破財等）＋ 聚財防漏財指南。
  5. **【感情婚姻與家庭模式】**：世應五行互動（主動付出型、被呵護型、平等夥伴型）＋ 相處箴言。
  6. **【身心五行養生調理】**：世爻對應中醫經絡臟腑弱點與保養之道。
  7. **【終身開運錦囊】**：專屬幸運色、開運吉數、生旺貴人方位、人生座右銘。
  - 支援 **「一鍵複製整份個人報告文本」**。

### 模組三：雙人命卦合盤（契合度與相處指南）
- **雙方生辰輸入**：分別輸入甲方、乙方資料（支援國曆/農曆，時辰可留空）。
- **合盤演算法與分析報告**：
  - **契合度總評板**：0~100% 契合度得分、吉凶星級、格局標籤（如：天作之合、相輔相成、歡喜冤家...）。
  - **雙方命盤要素對照**：雙方世爻五行、持世六親、六神臨位並列速覽。
  - **五行生剋與能量流向**：分析誰生誰（包容付出方）、誰剋誰（主導決策方）或同氣比和（默契好友）。
  - **性格碰撞與思維盲點**：兩人在價值觀與處世心態上的差異解析。
  - **相處優勢 vs 潛在地雷區**：列出雙方的默契契合點，以及最容易引發爭執的潛在地雷（金錢觀、溝通、情緒、面子）。
  - **【重要核心】雙方專屬相處指引**：
    - 💖 **給甲方的相處錦囊**：如何讀懂乙方的心、如何化解對方的固執、講話避雷指南。
    - 💖 **給乙方的相處錦囊**：如何體恤甲方的付出、如何給予安全感與支持、維護尊嚴的相處技巧。
    - 🌟 **雙方溝通黃金法則**：衝突三分鐘熄火守則、每週心靈復盤、共同願景錨定。
  - 支援 **「一鍵複製雙人合盤報告」**。

## 🛠 技術架構與模組設計

```text
ask5/
├── .github/workflows/deploy.yml  # GitHub Actions 自動部署腳本 (自動發布至 gh-pages)
├── dist/                         # Vite 編譯產出的純靜態發布包
├── src/
│   ├── data/
│   │   └── constants.js          # 八卦基礎數據、六十四卦完整資料庫、納甲表、八宮歸屬、地支刑沖合害
│   ├── utils/
│   │   ├── lunar.js              # 1900-2100 萬年曆、公曆/農曆轉換、四柱干支計算、梅花/終身卦起數
│   │   └── iching.js             # 六爻排盤、互卦、旺相休囚、一事一占計分引擎、終身卦報告生成、雙人合盤評估
│   ├── App.jsx                   # 主畫面 UI、三大分頁切換與交互邏輯
│   ├── main.jsx                  # React 掛載入口
│   └── style.css                 # 全局樣式
├── index.html                    # 頁面入口 HTML
├── package.json                  # 專案依賴 (React 18, Vite, Tailwind CSS, Lucide React)
├── vite.config.js                # Vite 配置 (base: '/ask5/')
└── README.md                     # 本專案說明文件
```

### 技術特點
- **前端框架**：React 18 + Vite 5 + Tailwind CSS
- **圖標庫**：Lucide React
- **純前端運算**：所有萬年曆轉換、卦象計算、評分演算法與評語生成全部在瀏覽器端本地完成，零伺服器維護成本，隱私安全無虞。
- **無縫部署**：Vite 配置了 `base: '/ask5/'`，只要推送到 `main` 分支，GitHub Actions 就會自動編譯並更新 GitHub Pages。

## 💻 本地開發與構建

### 1. 安裝依賴
```bash
npm install
```

### 2. 本地開發預覽
```bash
npm run dev
```

### 3. 編譯生產版本
```bash
npm run build
```

### 4. 部署至 GitHub Pages
代碼推送到 `main` 分支即可自動部署：
```bash
git add .
git commit -m "更新說明或新功能"
git push origin main
```
部署完成後即可在 `https://den3do.github.io/ask5/` 查看最新成果。
